 Reflection

 What I Learned

In this laboratory activity, I learned the importance of understanding the Linux environment before working with cloud infrastructure. I practiced using the terminal, navigating directories, creating files, and organizing a project workspace.

I also learned how Git and GitHub can be used to manage and document technical work. Using version control allows changes to be tracked and provides an organized way to maintain a professional Cloud Computing Portfolio.

 Challenges Encountered

One of the challenges I encountered was working with the Linux and Git environments and making sure that the required files were organized correctly. I also encountered a Git merge conflict while connecting my local repository with the existing GitHub repository.

I learned that conflicts can be resolved carefully by reviewing the affected files before committing the changes.

 Skills Developed

This activity helped me develop basic skills in:

- Linux command-line navigation
- File and directory management
- Markdown documentation
- Git version control
- GitHub repository management
- Technical documentation

 Conclusion

This laboratory activity provided a foundation for my Cloud Computing journey. I learned that proper organization, documentation, and version control are important skills for cloud infrastructure work. The portfolio created during this activity will also serve as a workspace for the succeeding laboratory activities.
