Laboratory 01 – Welcome to the Cloud

 Mission Overview

This laboratory activity introduces the basic responsibilities of a cloud infrastructure engineer. The mission focuses on accessing a cloud-based Linux environment, exploring the Linux operating system, gathering system information, organizing files and directories, and creating a professional GitHub portfolio.

Objectives

- Access a cloud-based Linux environment using KillerCoda.
- Explore and navigate the Linux operating system.
- Gather basic system information.
- Organize files and directories using Linux commands.
- Create and maintain a professional GitHub repository.
- Document technical work using Markdown.
- Demonstrate proper documentation practices used by cloud professionals.

 Activities Performed

- Accessed a Linux environment through KillerCoda.
- Explored the Linux terminal and basic commands.
- Created and organized directories and Markdown files.
- Gathered basic Linux system information.
- Created a GitHub repository for the Cloud Computing portfolio.
- Connected the local Git repository to GitHub.
- Documented the laboratory activities using Markdown.

 Linux Commands Used

- pwd – displays the current working directory.
- whoami – displays the current username.
- hostname – displays the system hostname.
- ls – lists files and directories.
- cd – changes the current directory.
- mkdir – creates directories.
- touch – creates files.
- cat – displays file contents.
- uname – displays system information.
- git status – displays the current Git repository status.
- git add – stages changes.
- git commit – records changes in Git.
- git push – uploads changes to GitHub.

Skills Learned

Through this laboratory activity, I learned how to work with a Linux terminal, navigate directories, create and organize files, collect basic system information, use Markdown for technical documentation, and manage a version-controlled project using Git and GitHub.
